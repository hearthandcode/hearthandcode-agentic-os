# One-Page Plan Template

The lean working plan: decisions only, evidence cited behind the page. Fill in order; if a section will not fit, the thinking is unfinished — compress the decision, not the truth. Rewrite monthly in the first six months; version it (v1, v2...) in the corner. Instructional comments in blockquotes; delete before use.

> **Fill order:** 1–3 first (they constrain everything), then 4–6, then 7–10. Target: fits on one printed page at normal font size.
