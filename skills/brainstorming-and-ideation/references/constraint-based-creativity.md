# Constraint-Based Creativity — Methodology

## Why Constraints Generate Novelty

The human brain responds badly to a blank page. Given an unlimited problem, the brain defaults to the first well-worn path it can find. Given a specific set of restrictions, however, the brain must engage in problem-solving mode, which activates the lateral pathways for generating workarounds and new approaches.

This is the paradox: creativity is not about removing limits. It is about designing them intentionally. A prompt like "design a game" leads to vague generic output. A prompt like "design a game with no dice, no board, and no cards, that two people can play in 10 minutes on a park bench" produces a flood of actual ideas.

## Sources of Useful Constraints

### 1. Budget constraints
"What could we do with exactly 15 staff instead of 40?" — forces elimination of luxury.
The constraint forces: "We must do what we must do without certain options."

### 2. Time constraints
"How would we solve this if we had to ship the minimum viable version by this week?" — removes all investment that can be proven risky beyond a specific threshold.

### 3. Format constraints
"No text. Only icons. Only black and white. Maximum 30 seconds." The format restriction forces the form of the solution.

### 4. Material constraints
"No new software. Only what is in the current tech stack. No new hires. One developer. No new versions of existing tools."

### 5. Process constraints
"Solve the problem without any meetings." "Skip the strategy phase project."

## How to Design Constraints

**Step 1 — List the current constraints (often implicit):**
- There are X time to decide.
- There is budget Y.
- The tool is Z.
- A solution must be complete.
- The client must approve the work before the next site.

**Step 2 — Identify the constraints without which the problem changes completely:**
- "What if the resource is zero?"
- "What if the timeline is half?"
- "What if we cannot use the main technology?"
- "What if they cannot talk to the customer directly?"

**Step 3 — Impose 1-3 new constraints and ideate:**
- The best numbers are 2-3 constraints in play. More than 3 constraints can be minimal and uncreative.
- The constraints must be spaced and not all at the same cost.

**Step 4 — Then remove a different set of constraints:**
- "What if the audience was doubled?" "What if a resource X constraint was removed?" — sometimes the creative path is not in adding constraints but removing one that was implicitly blocking ideas.

## Constraint Types in Action

### The "Zero" Constraint
Make one condition of the problem go to zero. If the deadline is zero, what's the negative ideal — and what's its opposite? If the budget is zero, what material is free? If personnel is zero, what can one person do?

### The "Inversion" Constraint
Take a basic assumption and flip it. "Our podcast uses narration over sound." Flip: "No narration, only sound." "Our spaces are designed for two-person teams." Flip: "Our spaces are designed for one person — then doubled."

### The "Absurd" Constraint
Build the craziest, most extreme version of the constraint that is still tractable. "We will produce daily content. " Each day has 24 hours of output." The extreme clarifies which part of the normal constraint is actually important.

## Design a Constraint Checklist

- [ ] Is the constraint contradictory to any other constraints? Do not create impossible combinations.
- [ ] Is the constraint challenging but not undermining the core objectives?
- [ ] Does the constraint have at least one obvious "break through"? If it it has no path to improvement, it is too restrictive — remove it.
- [ ] Is it possible to test the constraint for a single divergence round?
- [ ] Can the constraint be removed or extended based on what the divergence yields?

## When Constraints Fail

**Too many constraints:** When brainstorming under more than 3 constraints at once, the search space collapses entirely.
**The new constraint:** The constraint itself becomes the problem, not the original brief.
**The constraint that is a political issue:** "We have to include marketing's opinion" is a constraint about power, not about creativity.

## Constraint Budget Planning

For a session of 45 minutes with constraints:

- **Round 1 (15 min):** No constraints — generate baseline ideas (creates the control set).
- **Round 2 (15 min):** A positive constraint ("discover a new channel") or an elimination constraint ("cannot use the existing content").
- **Round 3 (15 min):** A bad/good combination of impact and feasibility: the worst outcome possible, the view of constraints boundaries.
