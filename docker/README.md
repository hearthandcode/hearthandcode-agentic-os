# Docker environment for hearthandcode-agentic-os

Run the agentic operating system inside containers for isolated,
reproducible sessions. Two base images are provided:

| Image | Target | Base |
|---|---|---|
| `Dockerfile.hermes` | Hermes Agent | `python:3.12-slim` |
| `Dockerfile.pi` | Pi coding agent | `python:3.12-slim` |

## Quickstart

```bash
# Hermes only
docker build -t agentic-os-hermes -f docker/Dockerfile.hermes .
docker run -it agentic-os-hermes

# Pi only
docker build -t agentic-os-pi -f docker/Dockerfile.pi .
docker run -it agentic-os-pi

# Both (docker compose)
docker compose -f docker/compose.yaml up
```

## What happens inside

Each container:
1. Installs the target agent harness (Hermes CLI or Pi)
2. Copies the agentic-os repository
3. Runs `python3 install.py --yes --target <name>` on first boot
4. Launches the agent's TUI or CLI

Volumes persist profiles, skills, and hub state across restarts.

## Generated vs shipped

The `Dockerfile.*` files are shipped with the repo. The `compose.yaml`
is generated by `install.py --setup-docker` to match your target selection.
You may also copy and customize the Dockerfiles for your own setup.
