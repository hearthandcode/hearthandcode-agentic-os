# AGENTS — Hub Governance and Orchestration Charter

## PURPOSE: Orchestration, governance, provenance, recovery document. Every profile reads this at session boot.

## 01 — Purpose and Scope

Occupies the hub root. Owns four things: orchestration (objectives, routing, layout), governance (ACK protocol), provenance (decision ledger), recovery (cold-start reader).

## 02 — ACK Signature Protocol

Every human decision that produces an effect requires an ACK string before execution. The ACK is generated by the profile at the decision point, presented to the human, and recorded in the ledger on confirmation.

Format: `ACK-{profile}-{sequence}-{8-char-hash}`

Kinds: effect (write/delete/move), gate (approve/reject), route (change routing), archive (close project), rollback (undo effect), governance (change AGENTS.md), objective (declare session goal).

Lifecycle: GENERATED → PENDING → CONFIRMED/REJECTED → RECORDED → CLOSED. Expired ACKs go to VOID.

## 03 — Decision Ledger

Active: `<hub-root>/08-meta/01-decision-ledger/README.md`. Append-only YAML blocks. No entry is ever deleted or edited. Corrections are new entries.

## 04 — Directory Layout: Topical-Indexed

Workspace is grouped by discipline. Folders for each major work domain.

| Folder | Purpose |
|--------|---------|
| `01-writing/` | Prose, articles, documentation, copy |
| `02-code/` | Code projects, snippets, scripts, abstractions |
| `03-design/` | Wireframes, comps, visual assets, design docs |
| `04-planning/` | Plans, schedules, decomposition, criteria |
| `05-research/` | Investigations, sources, literature notes |
| `06-archive/` | Completed topics, closed projects |
| `07-templates/` | Reusable scaffolds and templates |
| `08-meta/` | AGENTS.md copy, decision ledger, scripts, backup |

Subfolder convention: NN-kebab-name wherever a sequence matters.

## 05 — Recovery

If AGENTS.md is missing, hub is inoperative. Restore via installer.
